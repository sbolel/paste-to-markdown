About this project

Paste to Markdown

Paste to Markdown is a browser-based tool for converting rich clipboard HTML into clean, reusable Markdown. It is built and maintained by Sinan Bolel, published from the project repository, and deployed on GitHub Pages.

What the current app does

The canonical workspace app accepts rich-text pastes, converts them locally in the browser, shows raw Markdown, and lets you clear or copy the result. Pasted content is not sent to an app server.
